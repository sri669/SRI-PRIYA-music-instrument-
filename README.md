🎹 Band Organ Studio

A simple interactive virtual organ and band instrument website built with HTML, CSS, and JavaScript.

This project lets users play musical notes directly in the browser, experiment with chords, and create simple drum sounds without installing any additional software.

✨ Features

- 🎹 Interactive virtual piano/organ
- 🖱️ Play notes using the mouse
- ⌨️ Play notes using the computer keyboard
- 🎵 C Major chord playback
- 🥁 Basic drum sounds
- 🔊 Volume control
- 📱 Responsive design for different screen sizes
- ⚡ No external libraries required
- 🌐 Runs directly in a web browser

🛠️ Technologies Used

- HTML5 — Website structure
- CSS3 — Styling and responsive design
- JavaScript — Interactions and audio functionality
- Web Audio API — Generates the musical and drum sounds directly in the browser

2. Open the project folder.

3. Open "index.html" in your browser.
